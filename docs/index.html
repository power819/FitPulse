页面一览

移动端四页承载完整的用户旅程，后台三页服务于知识库与运营管理。点击卡片可查看对应设计说明。

01移动端 · 首页

智能教练对话

文字与图片双通道提问，回答以「要领 + 目标肌群 + 常见错误 + 出处」的结构化卡片呈现，每张卡都能继续追问。

SSE 流式动作卡快捷提问
02移动端 · 计划

训练计划

按水平、目标、器械与每周天数生成周计划，每天给出动作、组次与休息；勾选即打卡，进度环实时更新。

周切换打卡乐观更新完成率
03移动端 · 纠错

动作纠错

上传一张训练照片，返回整体评价与逐条问题：部位、问题描述、纠正建议、参考图，按严重程度着色。

视觉分析分级问题安全提示

个人中心

档案可编辑（水平 / 目标 / 器械 / 每周天数），训练天数、次数、时长与消耗四项统计，外加本周完成率。

三条主流程

原型的重点不在页面数量，而在用户与智能体之间的任务闭环——每次交互都要能走到一个可行动的结果。

A动作查询

不会练 → 看懂要领

  1. 点击「查动作」或直接提问
  2. 意图识别为动作查询，触发 RAG 检索
  3. 返回要领、肌群、呼吸节奏与常见错误
  4. 标注知识出处，可继续追问细节

B计划生成

不知道练什么 → 一周安排

  1. 读取档案（水平 / 目标 / 器械 / 天数）
  2. 工具按规则编排训练分割与动作
  3. 流式输出说明，并下发结构化计划
  4. 在计划页逐条打卡，进度回写统计

C动作纠错

怕练错 → 拍照诊断

  1. 上传照片并可选补充说明
  2. 视觉模型识别动作与偏差
  3. 逐条给出部位、问题、纠正与参考图
  4. 出现疼痛描述时追加就医提示

设计规范

全站共用一套设计令牌，原型与编码实现保持一致，避免「设计稿好看、实现走样」。
